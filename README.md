# pychat

**版本：pychat v1.0.0**

一个基于 Python + tkinter 的局域网即时聊天工具，包含服务器端与客户端端，纯标准库实现，零第三方依赖。

---

## 功能特性

### 服务器端

| 模块 | 能力 |
|---|---|
| **群聊** | 实时群聊广播、管理员发言、全局广播、清空聊天记录、消息历史（新用户上线自动推送最近 100 条） |
| **私聊** | 点对点私聊、私聊记录落盘查看与清空（超过 5MB 自动轮转归档） |
| **成员管理** | 踢出用户、禁言/解禁（支持分钟级与永久）、在线用户列表实时刷新 |
| **四级黑名单** | IP / MAC / 设备 ID / 硬件指纹，添加后立即踢出命中的在线用户 |
| **隐藏模式** | 一键隐藏服务器：不响应局域网扫描，且拒绝一切新连接，已在线用户不受影响 |
| **共享文件** | 上传/下载/删除共享文件，管理员可本地直传 |
| **IP 协议模式** | IPv4 / IPv6 / 双栈可切换，启动失败自动回退 IPv4 |
| **局域网发现** | UDP 广播自动发现服务器，客户端一键扫描 |

### 客户端端

| 模块 | 能力 |
|---|---|
| **聊天** | 群聊、私聊独立窗口、右键引用回复、一键复制 |
| **未读提示** | 群聊/私聊未读计数、窗口标题显示、任务栏闪烁提醒 |
| **消息草稿** | 输入内容自动保存到本地，30 秒自动保存一次，重启不丢 |
| **文件传输** | 点对点文件互传（需对方确认），带分片序号与 SHA-256 校验 |
| **共享文件** | 浏览、下载、上传服务器共享目录 |
| **断线重连** | 网络中断自动指数退避重连（最多 10 次），全程不弹窗打扰 |
| **服务器发现** | 扫描局域网服务器，双击即可填入 IP |

## 快速开始

### 环境要求

- Python 3.8 或更高（推荐 3.10+）
- 无需安装任何第三方依赖

### 启动服务器

```bash
cd pychat
python src/服务器.py
```

服务器启动后会显示监听端口（默认 `9999`）和本机可用 IP，把 IP 告诉客户端即可。

### 启动客户端

```bash
cd pychat
python src/客户端.py
```

1. 输入用户名
2. 输入服务器 IP（同一台机器测试可用 `127.0.0.1`）
3. 或点击「扫描局域网服务器」自动发现，双击列表项填入
4. 点击「登录连接」

> **快捷键**：`Enter` 发送，`Ctrl + Enter` 换行

### 打包为可执行文件

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name pychat-server src/服务器.py
pyinstaller --onefile --windowed --name pychat-client src/客户端.py
```

生成的 exe 位于 `dist/` 目录。

## 运行时数据

程序会在工作目录下生成以下文件（均已加入 `.gitignore`）：

| 文件 | 说明 |
|---|---|
| `blacklist.txt` | IP 黑名单 |
| `device_blacklist.txt` | MAC / 设备 ID 黑名单（格式 `标识\|原因`） |
| `hardware_blacklist.txt` | 硬件指纹黑名单 |
| `mute_list.txt` | 禁言列表（格式 `用户名\|解除时间戳`） |
| `server_hidden.txt` | 服务器隐藏状态（`0`/`1`） |
| `private_chat_log.txt` | 私聊记录 |
| `client_device_id.txt` | 客户端设备标识 |
| `message_draft.txt` | 客户端消息草稿 |
| `shared_files/` | 共享文件目录（最多 20 个文件） |

## 安全机制

- **管理员身份由服务端判定**，客户端无法伪造 `is_admin` 标记冒充管理员
- **文件传输全程 SHA-256 校验**，内容不符即拒绝落盘并删除
- **文件名强制清洗**，杜绝路径穿越（`../../etc/passwd` 会被清洗为 `passwd`）
- **用户名校验**：拒绝超长、控制字符、`()` 等会破坏显示名解析的字符
- **消息长度上限** 5000 字符，**连接数上限** 100，防御资源耗尽
- **隐藏模式**下不响应扫描也不接受新连接
- **硬件指纹**由 CPU / 硬盘 / 主板 / MAC / BIOS UUID 组合生成，修改 MAC 无法绕过

---

## 已知限制

- **IP 黑名单会波及同 IP 的所有用户**：局域网内若多台设备共用一个出口 IP，封禁该 IP 会一并踢出。建议优先使用 MAC / 设备 ID / 硬件黑名单。
- **黑名单标识可被客户端伪造**：MAC 与硬件指纹由客户端在登录时上报。硬件黑名单基于多因子组合，伪造难度较高，但并非密码学意义上的身份认证。
- **消息历史仅存于内存**：服务器重启后群聊历史丢失（私聊记录会落盘保留）。
- **未做端到端加密**：局域网内流量以明文传输，适用于可信内网环境。
